## 2. システム概要
本システムは、保険契約・保険商品・顧客情報を管理するWebアプリケーションです。
保険ポリシーの作成、編集、削除、検索、レポート出力を行うことを目的としています。

## 3. 機能一覧
| 機能ID  | 機能名      | 概要                         |
| ----- | -------- | -------------------------- |
| F-001 | 顧客管理     | 顧客の登録、編集、削除、検索を行う          |
| F-002 | 保険商品管理   | 保険商品の登録、編集、削除、カテゴリ分けを行う    |
| F-003 | 保険ポリシー管理 | 契約情報の作成、更新、削除、関連製品との紐づけを行う |
| F-004 | レポート出力   | PDF/CSV形式で契約状況を出力できる       |
| F-005 | ログイン/認証  | ユーザー認証、権限管理を行う             |

## 4. 画面設計
### 画面一覧
| 画面ID  | 画面名        | 概要                   |
| ----- | ---------- | -------------------- |
| S-001 | ログイン画面     | メールアドレスとパスワードでログインする |
| S-002 | 保険商品一覧画面   | 保険商品の検索と一覧表示を行う      |
| S-003 | 保険ポリシー編集画面 | 保険契約情報を編集する          |

### 画面詳細（例:　保険ポリシー編集）
| 項目      | 内容                              |
| ------- | ------------------------------- |
| 画面ID    | S-003                           |
| URL     | `/insurance_policies/{id}/edit` |
| 使用モデル   | InsurancePolicy                 |
| 入力項目    | 成約番号、開始日、満了日、金額、ステータス、関連製品      |
| バリデーション | 全項目必須、金額は数値、日付形式をチェック           |
| 備考      | ステータスはEnum(契約中/解約/失効)から選択       |

## 5. テーブル定義
### 5.1 insurance_policies
| カラム名            | 型             | NULL許可 | 備考                       |
| --------------- | ------------- | ------ | ------------------------ |
| id              | BIGINT        | NO     | 主キー                      |
| policy\_number  | VARCHAR(50)   | YES    | 成約番号                     |
| customer\_id    | BIGINT        | YES    | customers.id 参照          |
| start\_date     | DATE          | YES    | 契約開始日                    |
| end\_date       | DATE          | YES    | 契約満了日                    |
| premium\_amount | DECIMAL(12,2) | YES    | 保険料                      |
| status          | ENUM          | NO     | active/cancelled/expired |
| created\_at     | TIMESTAMP     | NO     | 作成日時                     |
| updated\_at     | TIMESTAMP     | NO     | 更新日時                     |


## 6. API設計
### 6.1 保険ポリシー更新API
| 項目     | 内容                                                     |
| ------ | ------------------------------------------------------ |
| メソッド   | PUT                                                    |
| URL    | `/api/insurance_policies/{id}`                         |
| リクエスト  | `{ "policy_number": "POL-12345", "status": "active" }` |
| レスポンス  | `{ "success": true, "message": "更新しました" }`             |
| エラーコード | 400: バリデーションエラー、404: データなし                             |

## 7. ビジネスルール
- 契約開始日は満了日より前でなければならない
- 同一顧客が同一保険商品を重複契約できない
- ステータスはEnum PolicyStatus のみを許可

## 8. 非機能要件
| 項目      | 内容                      |
| ------- | ----------------------- |
| セキュリティ  | ログイン必須、CSRF対策           |
| パフォーマンス | 1,000件以上の契約データでも1秒以内で検索 |
| バックアップ  | 毎日0時にDBダンプを自動保存         |

## 10. テスト観点
- [ ] 保険ポリシーを新規作成し、一覧に反映される
- [ ] ステータス変更がEnum通りに反映される
- [ ] 無効な日付を登録しようとするとエラーになる
- [ ] 多対多(ポリシーと製品)の関連付けが正しく保存される
